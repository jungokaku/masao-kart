# MASAO KART（マサオカート）

## 使い方

### 参加者
1. ページを開く →「キャラクター登録」で名前・顔写真・診断
2. 「大会に参加する」→ トーナメント表に入る（待っている間は「ひとりで練習」も可）
3. 大会が始まると自動でトーナメント表に切り替わり、自分の番になると自動でレース画面になる

### フリー対戦
1. 各自のPCで「フリー対戦」を押すとロビーに並ぶ
2. 2人以上そろったら、だれでも「スタート！」を押せる（最大4人、5人目以降は次のレース）
3. 全員ゴール、または1人目のゴールから30秒で順位確定 → ロビーに戻る
※ 大会中はフリー対戦できません

### 管理者（プロジェクターのPC推奨）
1. タイトル画面下の「管理者ログイン」→ パスワード（初期値 `masao`）
2. 右上の管理パネルで操作
   - **組み合わせをシャッフル／確定**
   - **大会スタート**：全員の画面がトーナメント表に切り替わる
   - **次のレース開始**：7秒後にスタート。出場者はレース画面、それ以外は観戦画面
   - **レース終了（今の順位で確定）**：全員ゴール前でも、その時点の順位で確定
   - **このレースをやり直す**／**トーナメントをリセット**／**全部リセット**
   - エントリーの削除（組み合わせ確定前のみ）
3. 全員ゴールすると自動で順位が確定。各レース上位2名が勝ち上がり、決勝1位が「マサオカート王」
4. 決勝は自動で「目黒川レインボーロード」になる
5. 大会終了後、管理パネルの「👑 優勝者ボーナスステージ開始」で、優勝者が30秒のスコアアタックに挑戦（全員が観戦）

観戦画面で **B** キーを押すとトーナメント表を重ねて表示できます。

大会中（大会スタート〜優勝決定）は、参加者・観戦者のPCは自動で消音になり、管理者の画面だけ音が出ます。

30人の場合の目安：1回戦8レース → 2回戦4レース → 準決勝2レース → 決勝（合計15レース、入れ替え込みで約50〜60分）。

## 2つの動作モード

| モード | 条件 | 範囲 |
|---|---|---|
| ローカルモード | `FIREBASE: null`（初期状態） | 同じPCのブラウザのタブ間だけ（動作確認用） |
| オンラインモード | `FIREBASE` に接続情報を設定 | 各自のPCから同じ大会に参加できる（本番用） |

同じPCで複数人を試すときは、URLの末尾に `?p=1`、`?p=2` … を付けて別タブで開くと別人として扱われます。

## Firebase の設定（本番で各自のPCをつなぐ場合）

1. https://console.firebase.google.com/ で「プロジェクトを作成」（Googleアナリティクスは不要）
2. 左メニュー「構築」→「Realtime Database」→「データベースを作成」→ 場所は「シンガポール」など → 「テストモードで開始」
3. 「ルール」タブを次の内容にして「公開」
   ```json
   {
     "rules": {
       "masaokart": { ".read": true, ".write": true }
     }
   }
   ```
4. 歯車 →「プロジェクトの設定」→「マイアプリ」でウェブアプリ（</>）を追加 → 表示される `firebaseConfig` の中身をコピー
5. `index.html` の `CONFIG` の `FIREBASE: null` を、コピーした内容に置き換える
   ```js
   FIREBASE: {
     apiKey: "…",
     authDomain: "…",
     databaseURL: "https://…firebasedatabase.app",
     projectId: "…",
     storageBucket: "…",
     messagingSenderId: "…",
     appId: "…"
   }
   ```
   `databaseURL` が入っていることを確認してください。
6. タイトル画面の下に「オンライン接続中」と出ればOK

> 注意：このルールはURLを知っている人なら誰でも書き込める設定です。飲み会が終わったらデータベースを削除するか、ルールを `false` に戻してください。管理者パスワード（`ADMIN_PASSWORD`）も必ず変更してください。

## GitHub Pages で公開する手順

1. GitHubで新規リポジトリ `masao-kart` を作成
2. `index.html` と `README.md` をアップロード
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後、`https://<ユーザー名>.github.io/masao-kart/` で遊べる

## 調整ポイント（`index.html` 内の `CONFIG`）

| 設定名 | 内容 |
|---|---|
| `LAPS` | 周回数（初期値 3） |
| `MAX_SPEED` | 最高速度 |
| `CPU_SPEEDS` | CPU 3台の速さ（ひとりで走るとき） |
| `BGM_VOLUME` | BGMの音量（0〜1） |
| `VOICE` | 「きゃっほー！」などの音声のON/OFF |
| `RACE_START_DELAY` | 「開始」からスタートまでの秒数（この間ステータス比較を表示） |
| `CPU_LEVEL` | CPUの強さの初期値（easy / normal / hard / oni） |
| `ITEMS` | アイテム・障害物のON/OFF |
| `PARK_SECONDS` | PARK24で駐車させる秒数 |
| `CATCHUP` | 追い上げ補正（0.05＝最下位は最高速度5%アップ、0で無効） |
| `TUBE_START_CAP` / `TUBE_PAD_CAP` / `TUBE_MAX_CAP` | 山手トンネルの最初の最高速度／矢印1つで上がる量／上限（×4でkm/h） |
| `FREE_WAIT_AFTER_GOAL` | フリー対戦で1人目のゴールから順位確定までの秒数 |
| `MAX_ENTRIES` | 大会のエントリー上限 |
| `ADMIN_PASSWORD` | 管理者パスワード |
| `ROOM` | ルーム名（URLに `?room=名前` を付けると別の大会） |
| `FIREBASE` | Firebaseの接続情報 |

診断の質問は `QUESTIONS`、ステータスの効き方は `applyStats` で変更できます。

## スマホで遊ぶ

- 同じURLをスマホで開くと、レース中に操作ボタンが出ます（横持ち）
- ハンドルは初期設定で「傾き」：スマホをハンドルのように左右に回すと曲がる。自動アクセルOFFなら前に倒してアクセル・手前に倒してブレーキ（タイトル画面の「ハンドル：ボタン」で ◀ ▶ ボタンに戻せる）
  - 左下：◀ ▶（ハンドル）／右下：ブレーキ・アイテム（自動アクセルOFFのときはアクセルも）
  - 画面左：自動アクセルの切替・一時停止（ひとり走行のみ）・音
- 曲がらないときはタイトル画面の「📱 傾きテスト」で確認：左右に回して黄色い丸が動けばOK。動かないときは「センサーを許可」を押す（iPhoneは許可が必要）
  - 1行目に原因と対処（https でない／LINE・Chatworkなどのアプリ内で開いている／許可しないを選んだ／Androidのモーションセンサー設定）が出ます。「診断」の行には端末・ブラウザ・受信回数が出ます
  - 向きセンサーが動かない端末では、自動で加速度センサーに切り替えて傾きを計算します
  - どちらも使えないときは、レース中に ◀ ▶ ボタンが自動で出ます
  - 感度は「ふつう（20°でハンドルいっぱい）」が初期値。少しの傾きではゆるく、大きく回すほど鋭く曲がります。曲がりすぎるときは「低」「とても低い」、回しすぎて画面が縦になるときは「高」
  - レース中は画面の向きを固定して計算するので、少し回しすぎても操作は続きます。縦向きが1秒以上続いたときだけ「横向きにしてください」が出ます
  - 確実なのはスマホの「画面の向きをロック（横）」をオンにすること。Androidは「全画面」ボタンでも横向きに固定されます
- スマホでは画質を自動で軽くします（解像度・街並み・粒の数を削減）。PCの画質は変わりません
- タイトル画面で「画質：自動／高／低」「操作ボタン：自動／表示／非表示」を変更できます
- Androidは「全画面」ボタンで広く使えます。iPhoneはSafariで開いてください（ホーム画面に追加したアイコンから開くと、傾きセンサーが使えないことがあります）
